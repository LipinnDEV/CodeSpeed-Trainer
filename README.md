# CodeSpeed Trainer

O CodeSpeed Trainer é um jogo de digitação feito com React.

O objetivo é digitar as palavras mostradas na tela com rapidez e precisão.

## Sobre o projeto

Durante o jogo, o usuário pode acompanhar:

- Pontos
- Tempo
- Combo
- Precisão
- Velocidade
- XP
- Moedas
- Nível

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript

## Recursos

- Partidas de 30, 60 ou 120 segundos
- Sistema de pontos
- Sistema de combo
- Sistema de níveis
- Ranking
- Histórico de partidas
- Recorde pessoal
- Escolha de nome e avatar
- Modo claro e escuro
- Palavras com diferentes níveis de dificuldade

## Palavras

O jogo possui palavras fáceis, médias e difíceis.

As palavras são escolhidas de forma aleatória e algumas palavras recentes são evitadas para deixar as partidas mais variadas.

## Dados

O navegador salva algumas informações do jogador, como:

- Nome
- Avatar
- Recorde
- Histórico
- Ranking
